# 泡泡笔记

离线学习记录应用。可以建立分区、记录和小 tip，在 tip 中手写、输入文字、插入图片或 PDF。PDF 可以逐页手写并导出带批注的文件。记录在列表中长按改色；长按后移动仍可拖动。数据保存在设备本地，不需要登录。

在记录里点「⇪」可导入 PDF 题库。应用在设备上识别题号，导入前可拖动分割线、补加或合并；跨页题可用「页首接上题」或将下一页首题接到上题。确认后每题生成一个小 tip，多个 tip 共用一份原始 PDF。题目上可直接手写，点「⛶」展开大画布后还能缩放和移动；橡皮只擦笔迹。首次使用离线识别也不需要网络。扫描件识别可能有误，请在预览中检查题目边界。

## 安装

面向支持 APK 安装的 Android 与 HarmonyOS 4.2。[下载 v1.2.0 安装包](dist/downloads/bubble-notes-question-bank-v1.2.0.apk)。使用同一签名升级安装可保留原有应用数据；升级前仍建议先导出备份。

## 数据

应用数据只在当前设备的应用存储中。换机、卸载或重装前，请在应用内导出备份。网站与已安装 APK 的数据不会自动同步。

## 开发

网页资源在 `dist/`，Android 封装与构建说明在 [`android-app/README.md`](android-app/README.md)。签名密钥不在仓库中；发布后续 APK 时必须沿用原密钥。
